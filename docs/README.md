`cli.md`, `docs/rules/`, `docs/patterns/` and the levels section of
`configuration.md` are generated by `rqx docs`, and a test fails when they differ
from the output of the binary. `man/` and `rqx.schema.json` are generated as well.
The other pages are written by hand.
