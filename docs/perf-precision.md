## Method

Every function in the corpus has a comment above it giving the time and space order a person worked out from the code, and the performance rules that should and should not report on it. The test runs the analysis `rqx perf` runs, extraction of each function followed by composition across calls and files, and compares the answer with the comment. The answer is exact when both orders are equal once the sizes are named alike, over when it is larger, under when it is smaller, and abstained when the analysis declined to give an order. Precision is exact answers over answered functions, recall is exact answers over all functions. A rule counts as right on a function annotated for it, as a false alarm on a function it reports without being annotated for it, and as a miss on an annotated function it does not report. Two rules that can both describe a call that walks a collection in a loop, `scan-in-loop` and `linear-op-in-loop`, accept either report.

The committed baseline records the outcome of every function and the count of every rule. The test fails when a function that was exact stops being exact, or when any language's precision or recall, or any rule's right, false alarm or missed count, gets worse. The baseline changes only when someone rewrites it with `RQX_BLESS=1`, so a drop shows in the diff of the commit that causes it. Where the analysis is wrong the annotation keeps the true answer and the baseline records the miss.

## Limits

The orders are worked out by reading code, not by running it. An empirical harness that times a function over a sweep of input sizes and fits the growth would catch an annotation that is itself wrong. The optional `tools/perf-validate` harness for this is out of scope for this release, so the annotations are not checked by measurement. The real sample is small, so one function moves a language by several points. A rule's recall is measured only on functions annotated for it, and the corpus does not annotate every function for every rule. Rules that the corpus has no annotation for have no row.
