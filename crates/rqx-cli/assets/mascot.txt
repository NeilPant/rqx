# rqx. An owl, seen head on. 12x12 pixels, two frames.
#
# S the plumage, H its shade, T the iris, K the pupil.
#
# S is resolved at render time from what the scan found, and H is that same colour
# darkened, so a failing repository is a red owl rather than a brown one with a small red
# detail somewhere on it. The eyes are the one part that never follows the verdict.
#
# The shade does the drawing: it is the facial disc around each eye, the ear tufts, the
# beak and the chest. A single flat colour with features punched out of it read as a
# potato with eyebrows.
#
# Head on rather than in profile. The last owl this project had was a profile with ear
# tufts and it read as a cat; tufts are safe here because two four-pixel irises are not
# something a cat has.
#
# Two pixel rows share one terminal cell, so the eyes are cell-aligned and four rows tall:
# the pupil spans the boundary between cell rows 2 and 3, which draws it as one dark band
# rather than as a half block adrift in a light one.
#
# The beak sits below the eye line rather than between the irises. Between them it shared
# its rows with the lids, so a blink merged the two into one bar across the whole face.
#
# The lid is the deliberate exception to cell alignment: it is a line, and which half of
# the cell it sits in is what separates a blink from a squint.
